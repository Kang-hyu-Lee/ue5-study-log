# Day 1 (extension) Solutions — Geometry & Trigonometry Basics

Only check these after attempting every problem yourself.

## 1. Legs 6 and 8 → hypotenuse?
```
a² + b² = c²
6² + 8² = c²
36 + 64 = c²
100 = c²
c = √100
c = 10
```
**Answer: 10** (this is a well-known "Pythagorean triple" — 6-8-10, a scaled version of 3-4-5.)

## 2. Hypotenuse 13, one leg 5 → other leg?
```
a² + b² = c²
5² + b² = 13²
25 + b² = 169         # rearranged to isolate b²
b² = 169 - 25          # subtract 25 from both sides
b² = 144
b = √144
b = 12
```
**Answer: 12** (another Pythagorean triple: 5-12-13.)

## 3. θ = 45°, hypotenuse = 10 → opposite?
```
sin(θ) = Opposite / Hypotenuse       # SOH: relates Opposite & Hypotenuse
sin(45°) = Opposite / 10
0.707 = Opposite / 10                 # given value from exercises sheet
Opposite = 0.707 × 10
Opposite = 7.07
```
**Answer: ≈ 7.07**

## 4. θ = 60°, hypotenuse = 8 → adjacent?
```
cos(θ) = Adjacent / Hypotenuse       # CAH: relates Adjacent & Hypotenuse
cos(60°) = Adjacent / 8
0.5 = Adjacent / 8
Adjacent = 0.5 × 8
Adjacent = 4
```
**Answer: 4**

## 5. θ = 30°, adjacent = 20 → hypotenuse?
```
cos(θ) = Adjacent / Hypotenuse       # CAH: relates Adjacent & Hypotenuse — matches what we have/want
cos(30°) = 20 / Hypotenuse
0.866 = 20 / Hypotenuse
Hypotenuse = 20 / 0.866               # rearranged: multiply both sides by Hypotenuse, then divide both sides by 0.866
Hypotenuse ≈ 23.09
```
**Answer: ≈ 23.09**

## 6. Why opposite/adjacent change but hypotenuse doesn't
The hypotenuse is defined by its position relative to the 90° angle (always opposite it) — that never changes no matter which of the other two angles you're focused on. "Opposite" and "adjacent" are defined relative to whichever angle θ you're currently analyzing, so swapping which angle you pick swaps which leg is "opposite" and which is "adjacent."
