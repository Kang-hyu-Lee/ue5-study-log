# Vectors — Exercises
Attempt by hand first (pure math, no code needed). Check against the solutions file only after attempting.

1. Given A = (5, 12), find |A| (magnitude).

2. Given A = (5, 12), find the unit vector (normalized direction).

3. Given A = (2, 3) and B = (-1, 4), find A + B.

4. A character at position (10, 10) wants to move toward position (13, 14). Find the direction vector.
   (hint: see the "Pitfall" section in the concepts file — one of the two subtraction orders is the one you want)

5. Using your answer from Q4, find the magnitude of that direction vector. What does this number represent in gameplay terms?
   (hint: think about what else you'd use this value for, besides direction)

6. What happens if you try to normalize (0, 0)? Explain why, mechanically — not just "it breaks."
   (see Edge Case in the concepts file)
