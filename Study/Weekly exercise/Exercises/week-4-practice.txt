CODING (polymorphism / virtual functions -- new this week)
C1. Write a base class Shape with a virtual function GetArea() returning 0.
C2. Write a derived class Circle : public Shape with a member Radius and an override of GetArea().
C3. Given Shape* S = new Circle(5); what does S->GetArea() call without virtual vs with virtual? Explain in a comment.
C4. Write a derived class Square : public Shape with Side and an override of GetArea().
C5. Write a function PrintArea(Shape* S) that calls S->GetArea() and prints it. Call it with a Circle* and a Square*.

MATH (rate of change / calculus intuition -- new this week)

M2. P(t) = 5t + 2. What is the rate of change?
M3. If position changes from 10 to 25 over 5 seconds, what is the average rate of change?
M4. P(t) = t^2. Estimate the rate of change between t=1 and t=2 using (P(2)-P(1))/(2-1).
M5. Same function P(t) = t^2, estimate rate of change between t=2 and t=3.
M6. What does it mean if the rate of change is negative? Give a movement example.
M7. What does it mean if the rate of change is 0?
M8. A car's velocity is constant at 10 m/s. What is its position function if it starts at position 0?
M9. If Position(t) = 4t^3, what physical quantity does the rate of change represent (in gamedev terms)?
M10. True/False: rate of change is the same as "derivative" -- if true, what does "instantaneous" add to that idea?
